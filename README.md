Project Description
The Smart Procurement Management System (SPMS) is a web-based application designed to simplify and automate the procurement process. It helps users manage purchase requests, receive quotations from sellers, and convert selected quotations into orders in an organized and efficient manner.

The system reduces manual work, improves transparency, and ensures better decision-making by maintaining all procurement data in a structured format.

🚀 Features
User registration and login (Customer, Seller, Admin)
Create and manage purchase requests
Seller quotation submission
Comparison and selection of quotations
Order generation and tracking
Role-based access control
Secure authentication using JWT
🛠️ Technologies Used
Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: MySQL
Security: JWT Authentication, Password Hashing
🔄 Workflow
User registers/logs into the system
Customer creates a purchase request
Admin reviews and approves the request
Sellers submit quotations
Customer selects the best quotation
Order is generated
Seller processes the order
Admin monitors the system
🗄️ Database Design

The system consists of the following main tables:

Users
Requests
Quotations
Orders

The database is normalized up to Third Normal Form (3NF) to ensure data consistency and reduce redundancy.

📈 Future Scope
AI-based recommendation for quotation selection
Mobile application integration
Real-time notifications and alerts
Advanced analytics and reporting
🎯 Conclusion

This project provides an efficient digital solution for managing procurement activities. It improves transparency, reduces manual effort, and supports better decision-making through structured data management.
